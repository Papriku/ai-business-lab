## LLM vs RAG vs AI Agent

### LLM
**Generates an answer** based on patterns learned during training.


User Question
↓
LLM
↓
Generates an answer



---

### RAG (Retrieval-Augmented Generation)
**Retrieves relevant information from external knowledge sources before generating an answer.**


User Question
↓
Retrieve relevant documents
↓
LLM
↓
Answer based on retrieved context


---

### AI Agent
**Plans, reasons, uses tools, evaluates results, and performs multiple actions to achieve a goal.**


Goal
↓
Plan
↓
Use tools (RAG, APIs, Jira, Outlook, SQL...)
↓
Evaluate results
↓
Take the next action
↓
Complete the task

> **An LLM answers questions, RAG answers questions using external knowledge, and an AI Agent completes tasks autonomously using reasoning and tools.** 🚀
